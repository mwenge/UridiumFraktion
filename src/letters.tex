You can forgive the temptation though, because the game's font glyphs are unquestionably stylish. By now we are used to the
Uridium author going a little further in his implementation of things than is necessary, pushing beyond what is perfectly adequate and
on to something approaching perfection. The game's lettering, which is used sparingly, is yet another instance where this is the
case. The hardware and design of the Commodore 64 almost railroads the developer into accepting a monochrome font that is eight
pixels wide by pixels high. Uridium ignores this constraint and replaces the default with a system that permits a number of features
invisible to the casual user, but are so fundamental to pleasant font rendering that we would indeed almost get away with using it
to typeset an entire chapter.

The mapping from source to destination involves a simple operation of interleaving each line in the definition with a blank line.
Put another way, we take each line our source on the left and add a blank line after it. This gives us a font glyph with its
baseline on the 5th line from the bottom. To accomodate this we must store our character using two definitions rather than one.
The upper half will be stored in the original 'source' definition 
(
\begingroup
\eurostilefont\scriptsize CHAR/0B
\endgroup
),
while the lower half
will be stored in a definition at a fixed offset of \icode{\$80} (128) bytes from the upper half 
(
\begingroup
\eurostilefont\scriptsize CHAR/8B
\endgroup
).

This mapping operation is implemented in the routine opposite, which takes the source definition of each character and
transforms it into two separate definitions.
\clearpage
\begin{lstlisting}[basicstyle=\scriptsize\ttfamily, escapechar=\%]
CreateUpperAndLowerHalvesOfTextCharset
  LDA #$80                   ; We are going to split 128 character definitions.
  STA numberOfCharsToSplit   ; So store that as the number of iterations to do.

CreateDestinationCharactersFromSource   
  LDX #$07                   ; Number of bytes to write from source char definition.
  STX posInSourceChar        ; Store in posInSourceChar.

  LDY #$07                   ; Number of bytes to write in the dest char definition.
StripeTheLowerHalf   
  LDA #$00                   ; Load 00 to A and use it to..
  STA (destCharLoPtr),Y      ; .. make a blank stripe at current pos.
  DEY                        ; Move Y to next pos in destinatinon char definition.
  STY posInDestChar          ; Store it in posInDestChar.
  LDY posInSourceChar        ; Get a line from the source character definition
  LDA (sourceCharLoPtr),Y    ; .. and store it in A.
  DEY                        ; Move Y to next pos in source char definition.
  STY posInSourceChar        ; Store it in posInSourceChar.
  LDY posInDestChar          ; Store the line from the source char definition..
  STA (destCharLoPtr),Y      ; .. in the destination pos char definition.
  DEY                        ; Move the next byte in the source char definition.
  BPL StripeTheLowerHalf     ; Keep going until all 8 are done.

  ; Move destination pointer to upper half charset at $7000
MoveDestinationPtrToUpperHalf
  LDA destCharHiPtr          ; Subtract 4 from the Hi Ptr to move..
  SBC #$04                   ; .. our destination pointer from $7400 .. 
  STA destCharHiPtr          ; .. to $7000, where the upper half chars are.

  LDY #$07                   ; Number of bytes to write in the dest char definition.
StripeTheUpperHalf                                                                   
  LDA #$00                   ; Load 00 to A and use it to..
  STA (destCharLoPtr),Y      ; .. make a blank stripe at current pos.
  DEY                        ; Move Y to next pos in destinatinon char definition.
  STY posInDestChar          ; Store it in posInDestChar.
  LDY posInSourceChar        ; Get a line from the source character definition
  LDA (sourceCharLoPtr),Y    ; .. and store it in A.
  DEY                        ; Move Y to next pos in source char definition.
  STY posInSourceChar        ; Store it in posInSourceChar.
  LDY posInDestChar          ; Store the line from the source char definition..
  STA (destCharLoPtr),Y      ; .. in the destination pos char definition.
  DEY                        ; Move the next byte in the source char definition.
  BPL StripeTheUpperHalf     ; Keep going until all 8 are done.

MoveDestPtrToNextCharacter
  LDA destCharLoPtr          ; Move the destination char pointer by..
  ADC #$08                   ; ..adding 8 to it to point to the next..
  STA destCharLoPtr          ; ..character definition we will write.

  ; Move destination pointer back to lower half charset at $7400
MoveDestPtrToLowerHalf
  LDA destCharHiPtr          ; Move the destination pointer..
  ADC #$04                   ; .. back to the 'lower half' defintions..
  STA destCharHiPtr          ; ..in preparation for the next iteration.

MoveSourcePtrToNextCharacter
  LDA sourceCharLoPtr        ; Move the source char pointer by..
  ADC #$08                   ; ..adding 8 to it to point to the next..
  STA sourceCharLoPtr        ; ..character definition we will write.

  DEC numberOfCharsToSplit   ; Decrement our loop counter and keep looping..
  BNE CreateDestinationCharactersFromSource ; .. until all are done.
\end{lstlisting}

Part of the trick here is to treat the top left character definition as the one that tells us we want to render a four-character
glyph. As we can see from inspecting the \icode{WriteCharacterToScreen} routine, any definition between \icode{\$3A} and \icode{\$59}
is treated as containing a four-character glyph. Determining the top right half of the glyph means adding a fixed offset of \icode{\$20}
to it (giving \euro{CHAR/5A} from \euro{CHAR/3A} in our example), while the lower halves are obtained by adding a fixed offset of \icode{\$80} (giving
\euro{CHAR/BA} and \euro{CHAR/DA} respectively).

\clearpage
\begin{lstlisting}[basicstyle=\scriptsize\ttfamily, escapechar=\%]
  ; Write a character to the screen. Take account of the fact that
  ; all characters will have a top and bottom half, and some such as
  ; capital letters will have 4 characters, two on top and two below.
WriteCharacterToScreen
  LDY currentCharYPos         ; Store Y position of char in Y.
  LDA screenLineHiPtrArray,Y  ; Use it to get the high byte pointer..
  STA screenCharHiPtr         ; .. and store it in screenCharHiPtr.
  LDA screenLineLoPtrArray,Y  ; Use it to get the low byte pointer..
  ADC currentCharXPos         ; .. offset with the X position of the char..
  STA screenCharLoPtr         ; .. and store it in screenCharLoPtr.

  LDA #$00                    ; Add any carry from the X position..
  ADC screenCharHiPtr         ; .. by adding the Hi Ptr to $00 and ..
  STA screenCharHiPtr         ; .. storing it.

  ; Write the top half of the character
  LDA charToWrite             ; Get the top half of the character.
  LDY #$00                    ; Write it to the position on screen..
  STA (screenCharLoPtr),Y     ; .. pointed to by screenCharLoPtr.

  ; Write the bottom half of the character
  ORA #$80                    ; Adjust A, e.g. turn $3A to $BA.
  LDY #$28                    ; Advance 40 positions to write it to..
  STA (screenCharLoPtr),Y     ; .. the position under the top char.

  ; Check if the character requires four characters to be written, e.g. 'A'.
  INC currentCharXPos         ; Move the next position on the screen.
  ; Characters between $3A and $59 have a second half. For example,
  ; capital A has a second half.
  AND #$7F                    ; Check the lower 7 bits of the char.
  CMP #$3A                    ; If it is less than $3A..
  BCC FinishedWritingChar     ; .. then we're done.

  CMP #$5A                    ; If it's greater than 59..
  BCS FinishedWritingChar     ; .. then we're done.

  ; Write the top half of the second part, for e.g. a capital letter.
  LDY #$01                    ; Point to the second half.
  ADC #$20                    ; Add $20 to turn e.g. $3A into $5A.
  STA (screenCharLoPtr),Y     ; Write it to the top right half.

  ; Write the bottom half of the second part, for e.g. a capital letter.
  ORA #$80                    ; Adjust A, e.g. turn $5A into $DA. 
  LDY #$29                    ; Advance 41 positions to write to..
  STA (screenCharLoPtr),Y     ; .. the position under the top char.

  INC currentCharXPos         ; Increase the X pos to match what we've written.
FinishedWritingChar   
  RTS                         ; We're done, return.
\end{lstlisting}
